Action button in the Console style — use for every clickable action; primary is reserved for the single main action of a surface (Send, Spawn session).

```jsx
<Button variant="primary">Spawn session</Button>
<Button small>Approve once</Button>
<Button variant="danger" small>Deny</Button>
```

Variants: primary (inverted), secondary (hairline, default), amber (needs-you register), danger (red). `wide` for full-width; `small` for in-card actions.
